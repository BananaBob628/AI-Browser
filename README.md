# 🌐 AI Browser  
### A modern Python web browser — **made with AI**

AI Browser is a sleek, intelligent, and lightweight web browser built in Python and designed with the help of AI.  
The name **AI Browser** literally means **“made with AI”** — from the UI layout to the code structure, the project was created with AI‑assisted development using CodeX.

---

## ✨ Features

- 🤖 **AI‑Assisted Design & Development**  
  The browser’s architecture, UI, and workflow were created with AI guidance, making the project clean, modern, and easy to extend.

- 🌐 **Modern Web Rendering**  
  Powered by PyQt6 + QtWebEngine for fast, secure, Chromium‑based browsing.

- 🎨 **Clean, Modern UI**  
  Gradient toolbar, rounded URL bar, and a minimal layout inspired by today’s top browsers.

- 🧭 **Smart Search**  
  Automatically detects URLs vs search queries and routes everything through Google.

- 🗂 **Multi‑Tab Support**  
  Open, close, and switch between tabs with a smooth, responsive interface.

- 🧩 **Modular Codebase**  
  Easy to customize, expand, and integrate new AI features.
